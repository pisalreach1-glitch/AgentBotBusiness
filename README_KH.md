# Telegram Business Agent Bot — Google AI Studio

Bot មួយ មាន Agent បី៖ បង្កើតផែនការ ពិនិត្យផែនការ និងរៀបចំការផ្សព្វផ្សាយ។
មុខងារបន្ថែមមាន ព័ត៌មានអាជីវកម្ម បញ្ជីការងារ ប្រវត្តិឯកសារ កំណែផែនការ និងទាញយក TXT។

## យកទៅប្រើជាមួយ Antigravity

1. ពន្លា ZIP ហើយបើកថត `business_agent_bot` ក្នុង Antigravity។
2. ភ្ជាប់ ឬចម្លងអត្ថបទទាំងមូលពី `ANTIGRAVITY_MASTER_PROMPT.txt` ផ្ញើទៅវា។
3. ប្រាប់វាឱ្យអានកូដ ពិនិត្យតាមការណែនាំ និងរត់តេស្តរហូតដល់ឆ្លងកាត់។
4. បញ្ចូលសោរបស់អ្នកក្នុង `.env` លើកុំព្យូទ័រ រួចចាប់ផ្ដើម Bot។

បើអ្នកយកតែ TXT អ្នកអាចបើកថតគម្រោងទទេ រួចផ្ញើអត្ថបទក្នុង TXT ទៅ Antigravity
ដើម្បីឱ្យវាបង្កើតគម្រោងតាមតម្រូវការដូចគ្នា។ ZIP មានកូដគំរូពេញលេញរួច។

## ដំឡើងនៅ Windows

ត្រូវមាន Python 3.11 ឡើងទៅ។ ការតេស្តក្នុងកញ្ចប់នេះប្រើ Python 3.12។

1. ចុចពីរដង `setup_windows.bat`។ វាបង្កើត `.venv` និងដំឡើង dependencies។
2. វាបើក `.env` ក្នុង Notepad។ បំពេញ `TELEGRAM_TOKEN` ពី BotFather និង
   `GEMINI_API_KEY` ពី Google AI Studio។ រក្សាទុកឯកសារ។
3. `GEMINI_MODEL=gemini-3.8-flash` ត្រូវបានបំពេញស្រាប់។ ប្ដូរវាបើគម្រោង
   AI Studio របស់អ្នកប្រើ Model ផ្សេងដែលគាំទ្រ structured JSON។
4. ចុចពីរដង `check_windows.bat` ដើម្បីរត់តេស្ត ដោយមិនប្រើ API ពិត។
5. ចុចពីរដង `start_windows.bat` រួចបើក Private Chat ជាមួយ Bot ហើយផ្ញើ `/start`។

កុំបិទផ្ទាំងដែលកំពុងរត់ Bot។ កុំព្យូទ័រត្រូវបើក និងមានអ៊ីនធឺណិតដើម្បីទទួលសារ។
ឯកសារ BAT និងតេស្តទាំងអស់ត្រូវបានរត់ និងផ្ទៀងផ្ទាត់ដោយជោគជ័យលើប្រព័ន្ធ Windows (Python 3.12)។

PowerShell បន្ទាប់ពីដំឡើងរួច អាចប្រើពាក្យបញ្ជាទាំងនេះនៅក្នុងថតគម្រោង៖

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m app.main
```

## ការកំណត់ API

កូដប្រើ Gemini Developer API តាម Google AI Studio និង `google-genai`។
វាមិនត្រូវការ Claude API ឬ OpenAI API ទេ។

```dotenv
TELEGRAM_TOKEN=បំពេញលើកុំព្យូទ័ររបស់អ្នក
GEMINI_API_KEY=បំពេញលើកុំព្យូទ័ររបស់អ្នក
GEMINI_MODEL=gemini-3.8-flash
DATABASE_PATH=data/business.sqlite3
TIMEZONE=Asia/Phnom_Penh
DAILY_AI_REQUEST_LIMIT=30
AI_MAX_OUTPUT_TOKENS=5000
ALLOWED_USER_IDS=
```

Google មាន Free tier សម្រាប់ Model មួយចំនួន ហើយមានដែនកំណត់តាមគម្រោង/គណនី។
កូដនេះមិនបើក Billing មិនប្ដូរ Model ស្ងាត់ៗ និងមិនបន្ថែម provider ផ្សេងទេ។
ចំនួន 30 ក្នុង `.env` ជាដែនកំណត់របស់ Bot ក្នុងមួយអ្នកប្រើក្នុងមួយថ្ងៃ
មិនមែនជាការបញ្ជាក់ថា Google អនុញ្ញាត 30 សំណើសម្រាប់គណនីគ្រប់គ្នាទេ។
សូមពិនិត្យ quota និងការកំណត់គណនីក្នុង AI Studio របស់អ្នក។

បើចង់អនុញ្ញាតតែអ្នកផ្ទាល់៖ ចាប់ផ្ដើម Bot ផ្ញើ `/id` រួចយកលេខនោះដាក់ក្នុង
`ALLOWED_USER_IDS` ហើយបិទ/បើក Bot ឡើងវិញ។ បើទុកទទេ អ្នកប្រើ Private Chat
ផ្សេងៗអាចប្រើបាន ដោយទិន្នន័យត្រូវបែងចែកតាមគណនីនិងអាជីវកម្ម។

## របៀបប្រើ

1. ចុច **🏢 អាជីវកម្មរបស់ខ្ញុំ → បង្កើតអាជីវកម្ម**។ ឆ្លើយសំណួរម្តងមួយ។
2. ចុច **📝 បង្កើតផែនការ** រួចជ្រើសប្រភេទ និងបំពេញគោលដៅ/រយៈពេល។
3. ក្រោយទទួលផែនការ ចុច **🔎 ពិនិត្យផែនការនេះ**។ Bot បញ្ជូនផែនការដដែលទៅ QA។
4. ចុច **✏️ កែផែនការតាមយោបល់** ដើម្បីបានកំណែថ្មី។ កំណែចាស់នៅរក្សាទុក។
5. ពីផែនការដែលបានកែ ចុច **📣 រៀបចំការផ្សព្វផ្សាយ** រួចជ្រើសប្រភេទមាតិកា។
6. ចុច **✅ ប្រើបញ្ជីការងារនេះ** លើផែនការដែលអ្នកជ្រើស ដើម្បីយកការងារទៅ
   **✅ ការងារថ្ងៃនេះ**។ អាចចុចថាធ្វើរួច និងបើកមើលការងារទាំងអស់។
7. ចូល **📂 ផែនការនិងឯកសារ** ដើម្បីបើក ផ្ញើឡើងវិញ ទាញយក ឬកែឯកសារចាស់។

ឧទាហរណ៍គោលដៅ៖ «រៀបចំបើកវគ្គភេសជ្ជៈថ្មី និងបង្កើនការចុះឈ្មោះក្នុងខែវិច្ឆិកា»។
សូមបំពេញតម្លៃ ថវិកា និងសមត្ថភាពទទួលសិស្សរបស់អ្នកពិតៗ។ Bot មិនមានទិន្នន័យ
ទីផ្សារ ឬចំនួនសិស្សរបស់អ្នកស្រាប់ទេ។

មិនលុបផែនការចាស់។ Wizard ដែលបានបំពេញមួយផ្នែកអាចបន្តតាម `/start`។
`/cancel` និង `/reset` ក្នុងកំណែនេះលុបតែការបញ្ចូលសំណើបច្ចុប្បន្ន មិនលុបឯកសារចាស់។
